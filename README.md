# Rahmatul Usra: Personal Site

The personal GitHub Pages site of Rahmatul Usra: a small static site with a home page and a few standalone pages, including a birthday page, an about page, and a quotes page.

**Live:** https://xsrazy.github.io

## About

This repository is the source of the xsrazy.github.io website, served directly by GitHub Pages. It is plain static HTML and CSS with a couple of music files, with no build step and no backend: what is in the repository is exactly what the site serves.

## Contents

- `index.html`: the home page ("Rahmatul Usra")
- `hbd/`: a happy birthday page
- `me/`: an about me page
- `quote/`: a quotes page
- `music.mp3`, `musik.mp3`: audio files used by the pages
- `style.css`: the shared stylesheet

## Architecture

- Plain static HTML and CSS, hosted on GitHub Pages from this repository's `main` branch
- No framework, no build step, no database, and no user data
